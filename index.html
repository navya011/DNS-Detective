DNS in 60 seconds

No networking background needed

Think of DNS as the internet's phone book. You know a website's name (github.com). Computers need its number (an IP address such as 140.82.113.3). DNS finds the number for you in a fraction of a second, every time you open a site.

  1. You type a name.Your browser needs the number behind it.
  2. A helper takes over.A server called a resolver does the searching for you, like a receptionist.
  3. It follows three directories.The root says who looks after .com. The .com directory says who looks after github.com. That site's own server gives the number.
  4. You get the number, and it is remembered.The answer is saved for a while, so next time it is instant.

Questions

Is DNS the same as the internet?

No. DNS is one service that runs on the internet. It only translates names to addresses. The actual page still comes from the website's server.

What are 8.8.8.8 and 1.1.1.1?

They are public resolvers, run by Google and Cloudflare. You can use them instead of your provider's resolver. This page asks Cloudflare.

Why can one site have several IP addresses?

Big sites spread visitors over many servers. DNS can return several addresses, or different ones depending on where you are, so no single server is overloaded.

What does the TTL number mean?

It is how many seconds an answer can be remembered. A low TTL (60) lets a site change servers quickly. A high one (86400, one day) means fewer lookups.

What is NXDOMAIN?

It means the name does not exist at all. This page stops the trace and shows it in red if you try a made-up domain.

Does this page show my computer's real DNS traffic?

No. A browser cannot send raw DNS packets. This page asks Cloudflare for the real name server records at each level, which rebuilds the real path a lookup follows.
